# Paradise Nursery Shopping Cart Application

A modern React and Redux Toolkit front-end web application for browsing and purchasing indoor houseplants.

## Features

- Landing page with the exact welcome message and Get Started button.
- About Us section with company information, mission, and services.
- 3 plant categories with 6 unique plants.
- Dynamic Add to Cart functionality.
- Add to Cart button changes to "Added to Cart" and becomes disabled.
- Redux Toolkit state management.
- Dynamic cart quantity badge.
- Individual item subtotal calculation.
- Dynamic total cart amount.
- Increment and decrement quantity controls.
- Delete items from the cart.
- Continue Shopping and Checkout buttons.

## Plant Categories

1. Air Purifying Plants
2. Aromatic Houseplants
3. Succulent Plants

## Technologies

- React
- Redux Toolkit
- JavaScript
- CSS
- Vite
